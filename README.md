# LapMob Budget Tracker

Firebase-backed budget tracker for phone and laptop use.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `app.js` — application logic, Firebase Auth, and Firestore
- `firebase-config.js` — Firebase web-app configuration

## GitHub Pages
Put all four source files in the same folder/repository and publish that folder with GitHub Pages.

## Firebase
The app uses Firebase Authentication (anonymous sign-in) and Firestore.
Use Firebase Security Rules to control access to your database.
